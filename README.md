This was a project I made back in 2023 during my university internship course. 
It's a web aplication that utilizes Google Books API for users to search books and add them to their private bookshelf.
Users can register and log in to their account (No server connection, instead Local Storage is used).
Search is available without registration.
Technologies and methodologies used: HTML, CSS, SCSS, JavaScript, Google Books API, Local Storage, asynchronous JS methods, responsive design, etc.
